What to leave out

      
One pattern per line. Leave this empty unless something specific needs skipping.


      
      


      

        How patterns work
        

          logs skips anything called logs, at any depth.
          world/region skips exactly that, anchored at the instance root.
          ** crosses directories, * and ? stay inside one name,
          a leading ! puts something back that an earlier line took out,
          and a backslash makes the next character literal — which is how you name a file
          with brackets in it, such as mods/\[1.21.1\] Some Mod.jar.
